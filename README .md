# Machine Learning CIE 2 – Activity 2: Simple House Price Prediction

## Project overview
This project builds and evaluates a Simple Linear Regression model to predict a continuous house-price value using one input feature.

## Dataset
- **Name:** California Housing Dataset
- **Source:** https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_california_housing.html
- **Domain:** Housing / census-block-group information
- **Access:** Loaded in the notebook using `fetch_california_housing(as_frame=True)`.
- **Input feature (X):** `MedInc` – median income in tens of thousands of US dollars.
- **Target (y):** `HousePriceUSD` – median house value converted to US dollars from `MedHouseVal`.

The dataset is based on 1990 California census information and should not be treated as current house-market prices.

## Files
- `ML_CIE2_Activity2_House_Price_Prediction.ipynb` – notebook with code, explanations and visualizations.
- `README.md` – project description and execution instructions.
- `requirements.txt` – required Python libraries.
- `california_housing_selected_data.csv` – generated by the notebook.
- `test_actual_vs_predicted.csv` – generated test-set comparison.

## Work completed
1. Loaded and inspected the dataset.
2. Checked data types, summary statistics, missing values and duplicate records.
3. Selected `MedInc` as X and `HousePriceUSD` as y.
4. Visualized the feature-target relationship.
5. Split data into 80% training and 20% testing sets.
6. Trained Simple Linear Regression and recorded coefficient, intercept and equation.
7. Generated test-set predictions.
8. Evaluated using MAE, MSE, RMSE and R².
9. Visualized actual versus predicted values.
10. Generated a new example prediction.

## How to run
Open the notebook in Google Colab or Jupyter and run all cells from top to bottom. Internet access may be required to fetch the dataset. The notebook creates two CSV output files; download them and add them to the repository.

## Limitation
Only one feature (`MedInc`) is used. House prices also depend on location, property size, condition, age and other factors. The data is based on 1990 census information and is not a current market valuation source.
